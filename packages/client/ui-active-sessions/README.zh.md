# @deepseek-ai/dsh-client-ui-active-sessions

[English](README.md) | 中文

## 概述

`dsh-client-ui-active-sessions` 是 dsh Web 客户端的置顶活跃会话侧边栏浏览区变体：它把跨所有工作区中正在运行、等待用户交互或带未读完成提醒的会话统一提取到顶部的活跃区段，并严格按最近活动时间排序。它以遮蔽优先级 `-1` 挂载在 `sidebar.workspaces` 槽位，无需改动底层默认注册或其目录流选择器。活跃区段下方以可折叠的分组展示各工作区的剩余会话并提供快速新建动作。

<a id="use-this-package"></a>
## 使用本包

把活跃会话置顶的侧边栏浏览区变体（参见 [Agent Note](../../../.agents/notes/implemented/architecture/2026-08-26-ui-active-sessions-shadow-sidebar-cell.zh.md)）。本包以遮蔽优先级 `-1` 向侧边栏外壳的 `sidebar.workspaces` 槽注册 `ActiveSessionsBrowser`：槽系统渲染 single 单元的最低优先级在位者，因此本组件赢得该单元，而 ui-workspace 的原版浏览器注册（默认优先级 `0`）仍挂载在其下。移除本包的组合行——或在运行时释放其在位者——无需刷新即可把座位交还原版浏览器。由于被遮蔽的浏览器在挂载期间保留其目录流声明，本包自身不再声明任何子槽。

**进行中** 区段是一份跨工作区的统一列表，收录每条可见会话中摘要报告为运行中、存在待用户交互（审批、计划评审、提问）、或带未读完成提醒的行；行严格按最近活动排序，最新的在前，并标注所属工作区标题（游离会话回退到 cwd 基名）。打开某行经注入面调用 `ctx.sessions.open`，同时沿运行时常规选中路径清除该会话的完成提醒。活跃行从不在下方区段重复。可见性与原版规则一致：子代理来源的行只经其父会话目录进入；归档行处处隐藏；空白会话仅在其作为临时当前会话时显示，此时本地化的 **新会话** 占位标题使其工作区分组保持可见。

在进行中区段之下，每个工作区渲染为一个可折叠分组头（标题加剩余行数），成员行同样按最近活动而非宿端手动账户顺序排列——这是与原版浏览器 Manual 模式的既定差异。悬停分组头会把行数换成"新建会话"加号：在该工作区连接一条空白会话并打开（同时选中该工作区）；折叠的分组先展开，让新行可见。未分组桶没有可定位的工作区，悬停时保留原计数。提升后剩余行为空的分组保持隐藏，除非其中包含当前会话，因此置顶不会留下空分组。分组折叠是组件本地状态，默认展开。折叠侧栏下，区域渲染一个展开侧边栏的搜索入口和活跃计数徽标。

非空搜索词会把主体替换为一份扁平结果列表：大小写不敏感的标题与工作区子串匹配即时取自列表数据，而排名式正文内容请求等待 250 ms 按键去抖。内容命中合并到本地段之下，摘录折入匹配行，不可见类别一律排除，合并列表以 `searchResultLimit` 封顶。选择结果打开该会话并清空搜索词。每个新查询中止前一个请求；失败或被超越的搜索保留上一页。行状态圆点复用共享的 `StateDot` 原语状态：琥珀色表示等待用户，蓝色追跑表示运行中，绿色表示完成提醒。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **遮蔽以牺牲原版浏览器能力为代价**——本在位者胜出期间，侧边栏区头没有添加工作区快捷方式（新会话首屏选择器仍可添加工作区），也没有行级上下文菜单（重命名、分叉、归档、拖拽排序）。
- **排序恒为最近更新**——原版浏览器持久化的手动拖拽排序偏好在此既不生效也不可编辑；本变体没有任何拖拽面。
- **不聚合运行中后代**——与原版不同，后代子代理会话运行时本行只点亮自身状态点；其后代活动在父会话的子代理目录中可见。
- **分组折叠不跨重挂载保留**——按设计折叠状态是组件本地状态，区域重挂载时重置。
